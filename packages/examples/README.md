# Nook examples

A home for demonstrations of Nook features across its packages.

Examples show how the native browser primitives work in practice and how Nook can be used. They are intentionally styled, while `@nook/core` remains styleless.

Run the examples from the repository root with `pnpm dev:examples`, or from this folder with `pnpm dev`. Build a production preview with `pnpm build` and inspect it with `pnpm preview`.

The first page demonstrates a click popover whose trigger keeps an ordinary application click handler, and a tooltip triggered by hover or focus. Select is the next example and primitive to shape. Its workspace name, `@nook/examples`, is provisional and private.
